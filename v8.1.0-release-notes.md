## 🌊 Wave 17 Highlights (v8.1.0)

- **Stop stream** — cancel AI response mid-generation via `aiJob.cancel()`

## 🌊 Wave 1-16 Summary (sebelumnya unreleased)

### Wave 1-2: Critical Stability + Security
- Scrollback, agent, sandbox, HOME path fix
- SSH TOFU before auth (dialog blocking sebelum kredensial dikirim)
- Rootfs SHA256 verify (fail-closed kalau checksum mismatch)
- Secure storage fail-closed (no plaintext fallback kalau Keystore gagal)
- MCP allowlist (block 169.254.169.254 cloud metadata + .internal)
- Agent ALWAYS_DENY + risk assessment (10 high-risk patterns)

### Wave 3-4: UX + Agent Tools
- IME input fix (typed characters tidak vanish)
- Block live updates (palette recents, diff apply)
- Reaper thread (zombie process cleanup)
- Autocomplete dari persistent history
- `grep_content` tool (content search, MAX_GREP_MATCHES=40)
- Safe read/delete (MAX_READ_CHARS=5000, MAX_READ_BYTES=2MB)
- Output ring buffer (16,000 chars) + clean output cap (8,000 chars)

### Wave 5-6: PtySessionBase + Anthropic + UX
- `PtySessionBase` — shared PTY session core untuk local + proot
- **Anthropic Native API** (`apiStyle: anthropic`) — Claude via Messages API
- Wide-char support (combining marks, CJK width 2)
- `AiMetrics` — lightweight observability (latency + size proxies)
- Explorer cd, editor confirm, SFTP limits (MAX_SFTP_CHARS=512,000)
- Agent clarify (AI bisa minta clarification via `<needs_clarification>`)
- MCP ping health-check

### Wave 7-9: Release Polish + History + Export (v7.3.0-v7.5.0)
- Persistent command history (survive app restart, shared for autocomplete)
- Export transcript (terminal output ke txt)
- URL validator (auto-prepend https://, reject HTTP non-localhost)
- Chat export (AI chat ke txt)
- Snippet type-in
- SSH host keys list + clear

### Wave 10-11: Tabs + Bookmarks + IME Fix (v7.6.0-v7.6.1)
- Tab rename (long-press tab)
- Bookmarks (`bookmark add/list/go/remove`, quick cd)
- Copy-output command
- Keep-screen-on (default on)

### Wave 12-13: Terminal Max Polish + Scrollback Select (v7.7.0-v7.8.0)
- Safe paste (bracketed paste mode, flatten newlines, 64KB cap)

- Jump-to-bottom, faster row render, IME sync

### Wave 14: Find + Mouse + Reconnect (v7.9.0)
- `find <query>` search di scrollback
- `open-url` / Open URL chip (detect http(s) URL di output)
- Mouse wheel + mode 1000/1006 (SGR)
- Reconnect keep history (restart session tanpa hapus scrollback)
- ExtraKeys F1-F4 + `^A`/`^E`

### Wave 15-16: LazyColumn + Unicode + Font Zoom (v8.0.0-v8.0.1)
- LazyColumn virtualized scrollback (hingga 2000 rows tanpa lag)

## 📦 Installation

### Download APK
Download `tunnel-terminal-v8.1.0-full-arm64.apk` dari release assets di bawah.

### Install
1. Enable "Install from unknown sources" di Android settings
2. Tap APK untuk install
3. Target: arm64-v8a only (proot binary arm64)

### Build dari Source
```bash
git clone https://github.com/NanoMindExplorer/tunnel-terminal.git
cd tunnel-terminal
git checkout v8.1.0
./gradlew assembleFullRelease
```

**Requirements:** Android Studio Koala+ (AGP 8.5.2), Android SDK 34, NDK 25.1.8937393+, CMake 3.22.1, Kotlin 2.0.21, Gradle 8.9, JDK 17.

**Wajib sebelum build fitur Ubuntu:** obtain binary `proot` — lihat [`app/src/main/assets/proot/README.md`](https://github.com/NanoMindExplorer/tunnel-terminal/blob/main/app/src/main/assets/proot/README.md).
